# Q*thulhu

**Lovecraft Arcade Vol. 5** — A Dosswerks Arcade Game

A Q*bert-inspired arcade game set in the impossible geometry of R'lyeh. Play as Q*thulhu, a tiny incompetent Star-Spawn hatchling, hopping across cubes while dodging Cthulhu's tentacle eruptions and eldritch enemies.

## How to Play

- **Arrow Keys** (or WASD): Hop diagonally across cubes
- **Swipe** (mobile): Swipe in diagonal directions to hop
- Convert all cubes to clear each level
- Avoid tentacle eruptions (watch for green pulsing warnings)
- Catch Elder Signs to freeze enemies
- Jump onto Night Gaunts at board edges to escape back to the top

## Game Elements

- **Tentacle System**: Cthulhu's tentacles erupt from cubes, telegraphed by green pulsing
- **Deep Ones**: Basic roaming enemies with predictable movement
- **Mi-Go**: Random-path flying enemies (Level 2+)
- **Star Spawn Rivals**: Aggressive pursuit enemies (Level 4+)
- **Night Gaunts**: Escape transports hovering at board edges
- **Elder Signs**: Power-ups that freeze all enemies

## Running

Open `index.html` in any modern browser. No build step required.
